# Changelog

## 0.1.0 — 2026-10-19

- Initial public release of Astro Answers for Linux.
- Spelling and Maths modes on one shared arcade game.
- ×2 through ×12 progression with mixed endless Maths play.
- Three-level asteroid fragmentation, wrapping movement, shields, waves and scoring.
- Global answer selection with mid-answer switching and prefix-ambiguity protection.
- Separate persistent top-five Maths and Spelling score tables.
- Full-screen 4:3 presentation with aspect-preserving scaling.
- Original embedded sprites and nine original sound cues.
- Deterministic core tests, race testing and Linux ARM64 build gate.
